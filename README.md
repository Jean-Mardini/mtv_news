# MTV News – Android UI

A single-screen Android app built with **Kotlin** and **Jetpack Compose** that recreates a TV-channel news feed: category tabs (All, Important, Local, International), a scrollable list of headlines with timestamps, and "breaking" highlights.

A Jetpack Compose UI exercise. The headlines are static sample data; the app does not call a news API.

## Tech

Kotlin · Jetpack Compose · Material 3 · Gradle (Kotlin DSL)

## Run

Open the project in Android Studio and run the `app` configuration on an emulator or a device (minimum SDK 36).
